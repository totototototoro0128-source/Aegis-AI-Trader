# Aegis AI Trader

日本株の分析と、FX・日本株の自動売買を試せる Streamlit アプリです。自動売買はペーパートレード専用で、証券会社やFX業者へ実際の注文は送りません。

## 主な機能

- 日本株の監視リスト、株価チャート、MACD、RSI、テクニカル指標に基づく売買シグナル
- 株価チャート、MACD、RSI、シグナルの表示切替とレイアウト調整
- 日本市場、為替、金属・商品の価格モニター
- USD/JPY・EUR/JPY・GBP/JPY のFXペーパートレード
- 銘柄コードから取引対象を追加できる日本株ペーパートレード
- FX・日本株それぞれ100万円の独立したデモ口座と3種類の運用モード
- 取引履歴、保有ポジション、純資産推移、価格チャート、FXバックテスト

売買シグナルは現在、移動平均やRSIなどのルールに基づく判定です。外部の生成AIによる発注判断や実際の自動発注は実装していません。

## ローカルで起動

Python 3.12以降を用意してください。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501/` を開きます。初回起動時に `database/investment.db` が作成されます。デモ口座、監視リスト、レイアウトはローカル環境に保存されます。

価格データは主に Yahoo Finance / `yfinance` から取得します。配信遅延や取得失敗があり、取引所のリアルタイム価格を保証するものではありません。画面を閉じたりサーバーを停止したりすると、デモの定期評価も停止します。

## 公開時の注意

`database/investment.db`、価格キャッシュ、仮想環境、認証情報はGitの追跡対象から除外しています。GitHubにコードを置くだけではStreamlitアプリは常時稼働しません。公開サイトとして使う場合は別途ホスティングが必要です。
